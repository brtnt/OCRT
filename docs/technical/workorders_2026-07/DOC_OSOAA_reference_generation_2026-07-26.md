# OSOAA 기반 기준자료 생성 — 수면 위 반사도의 직접 산출

논문 초고용. OCRT 검증에 쓰는 OSOAA 기준자료 중 **수면 위 원격반사도**를 어떻게
얻는지, 그리고 왜 기존의 두 단계 차감법을 버렸는지 정리한다.

---

## 1. 문제 — OSOAA는 수출광을 따로 내주지 않는다

OSOAA는 대기와 해수를 결합해 푼 뒤 지정한 준위의 복사휘도를 출력한다. 해면 바로
위 준위(0⁺)의 상향 복사휘도 `L_up(0⁺)` 는 두 성분의 합이다.

```
L_up(0+) = L_refl  +  L_w
```

- `L_refl` : 해면이 되비친 하늘광
- `L_w`    : 해수에서 올라와 계면을 투과한 수출광

원격반사도 `Rrs(0⁺)` 의 정의에 필요한 것은 `L_w` 뿐이다. 그러나 OSOAA의 표준
출력은 둘의 합만 준다.

---

## 2. 기존 방법 — 두 단계 차감

같은 대기·같은 해면·같은 기하로 두 번 실행하고 뺐다.

1. 실제 해수 실행 → `L_up(0⁺)`
2. **흑색 해수** 실행 → `L_refl^black`. 흡수 10 m⁻¹, 깊이 5 m, 검은 바닥을 두어
   수출광을 없앤 해수다.
3. `L_w ≈ L_up(0⁺) − L_refl^black`

OSOAA는 순수 해수 분자산란을 끌 수 없으므로 흑색 해수는 완전한 흡수체가 아니라
근사다. 이 근사가 두 가지 문제를 낳는다.

---

## 3. 왜 오차가 컸는가

### 3.1 상쇄에 의한 상대오차 증폭

준위 0⁺의 상향 복사휘도는 되비친 하늘광이 지배한다. 본 연구의 조건에서
**세기의 약 96 %, Q 성분의 약 99.9 %** 가 `L_refl` 이다. 따라서 차감 후 남는
잔차가 원값보다 훨씬 작아지고, 원값에 실린 상대오차가 잔차에서는 크게 증폭된다.

차감 비 `|L_refl^black| / |L_up(0⁺)|` 를 전 조합(방향 8,450개)에서 집계했다.

| 성분 | 중앙값 | 90 백분위 | 비가 1을 넘는 방향 |
|---|---|---|---|
| I | 0.417 | 0.854 | 0 % |
| **Q** | **0.878** | **1.230** | **31.9 %** |
| U | 0.475 | 1.268 | 16.7 % |

Q는 방향의 3분의 1에서 **빼는 값이 원값보다 크다.** 두 큰 값의 차로 그보다 작은
잔차를 얻는 상황이므로, 상대오차가 구조적으로 부풀려진다. 실제로 오차는 차감 비에
따라 단조 증가한다.

| 차감 비 (Q) | 방향 수 | Rrs(0⁺) Q 평균 오차 |
|---|---|---|
| < 0.3 | 2,114 | 0.298 % |
| 0.5 ~ 0.8 | 1,378 | 0.622 % |
| 0.8 ~ 1.0 | 2,265 | 1.517 % |
| 1.0 ~ 2.0 | 2,311 | 1.265 % |

### 3.2 두 실행이 같은 물리계가 아니다 — 계통 성분

더 근본적인 문제가 있다. 차감법은 `L_refl^black = L_refl` 을 가정하지만 이는
성립하지 않는다. **대기와 해수가 결합돼 있기 때문이다.**

실제 해수는 밝고 흑색 해수는 어둡다. 해수에서 대기로 되돌아가는 빛의 양이 다르면
대기가 다시 내려보내는 하늘광 분포가 달라지고, 따라서 해면이 되비치는 양도 달라진다.
차감 후 남는 것은 순수한 수출광이 아니라 **수출광 + (되비침의 차이)** 다.

이 계통 성분의 크기를 직접 측정했다. 새 방법으로 얻은 수출광 `L_w^direct` 를 써서

```
L_w^direct + L_refl^black  =  L_up(0+)  ?
```

를 확인하면, 좌우 차이가 곧 `L_refl^black − L_refl` 이다.

| 관측천정각 | I | Q | U |
|---|---|---|---|
| 0도 | −0.082 % | +0.061 % | (양쪽 모두 ~10⁻¹⁹, 판정 제외) |
| 15도 | −0.087 % | +0.285 % | +0.504 % |
| 30도 | −0.122 % | **+5.969 %** | +0.467 % |
| 45도 | −0.263 % | **−2.670 %** | +0.318 % |
| 60도 | −0.789 % | **−2.217 %** | −0.156 % |

성분별 크기 순서(Q ≫ U > I)가 관측된 오차의 순서와 일치한다. 즉 기존 방법의
수면 위 오차는 대부분 이 두 가지, 특히 Q에서 지배적이다.

---

## 4. 새 방법 — 결합해에서 수출광 항을 직접 뽑는다

차감을 없애려면 수출광을 **하나의 실행 안에서** 분리해야 한다. OSOAA의 연속
산란차수(SOS) 해법이 이를 가능하게 한다.

OSOAA는 계면 연산자를 네 모드로 분리해 호출한다.

| 모드 | 뜻 |
|---|---|
| `TWA` | 물 → 공기 투과 (**수출광**) |
| `RAA` | 공기 → 공기 반사 (**되비침**) |
| `TAW` | 공기 → 물 투과 |
| `RWW` | 물 → 물 내부반사 |

각 산란차수의 계산 순서는 다음과 같다.

```
Etape 2  해수 내부 상향장 산출
Etape 3  TWA  ->  L_up(0+) 에 수출광을 대입             <-- 여기서 복사한다
Etape 5  대기 상향 전파
Etape 6~8 대기 하향장 산출
Etape 10 RAA  ->  L_up(0+) 에 되비침을 가산
```

**Etape 3 직후의 `L_up(0⁺)` 는 수출광만 담고 있다.** 되비침은 그 뒤 Etape 10에서
더해진다. 또한 Etape 3은 가산이 아니라 **대입**이고, 배열은 각 산란차수 시작에서
0으로 초기화된다. 따라서 이 시점의 값을 복사하면 순수한 수출광이 얻어진다.
**차감이 개입하지 않는다.**

### 4.1 수정 내용

`OSOAA_SOS_CORE.F` 의 Etape 3 직후 **네 곳**(거친 해면·평면 해면 × 산란차수 1차·N차)에
기록 블록을 넣었다. 기록 형식은 `WL <푸리에차수> <방향지수> <I> <Q> <U>` 이다.

두 가지 설계 원칙을 지켰다.

1. **기존 계산에 손대지 않는다.** 값을 읽어 파일에 쓸 뿐 어떤 변수도 수정하지 않는다.
2. **환경변수로 게이트한다.** `OCRT_WL_FILE` 이 설정된 경우에만 동작한다. 설정하지
   않으면 기존 OSOAA와 출력이 완전히 동일하다.

### 4.2 방위각 재구성

SOS는 방위각을 푸리에 급수로 분해해 차수별로 푼다. 따라서 기록된 값은 물리
복사휘도가 아니라 **푸리에 모드 계수**다. `OSOAA_TRPHI` 와 동일한 규약으로
재구성한다.

```
I(phi) = sum_m  w_m * I_m * cos(m*phi)
Q(phi) = sum_m  w_m * Q_m * cos(m*phi)
U(phi) = sum_m  w_m * U_m * sin(m*phi)
w_0 = 1,   w_m = 2  (m >= 1)
```

이 성질이 부수적 이점을 준다. **한 번의 실행으로 전 방위각을 얻는다.** 기존에는
방위각마다 실행하고 흑색 해수까지 한 번 더 돌려야 했다.

| 항목 | 기존 | 신규 |
|---|---|---|
| 조합당 OSOAA 실행 | 26 회 | **1 회** |
| 47개 조합 전체 | 약 620 회 | **47 회** |

## 5. 검증

네 단계를 통과했다.

1. **재현성** — 소스에서 다시 빌드한 실행파일이 배포 실행파일과 출력 전 자릿수 일치.
2. **무해성** — 환경변수 미설정 시 기존 출력과 완전 동일.
3. **항등식** — `L_w^direct + L_refl^black = L_up(0⁺)`. 잔차가 곧 기존 방법의
   계통 오차이며, 3.2절의 표가 그 측정값이다.
4. **교차검증** — 차감 비가 작아 기존 방법이 신뢰할 수 있는 방향(비 0.3 미만)에서
   두 방법이 1 % 이내로 일치.

## 6. 결과

전 계열(CDOM 3단계 × 5밴드, 총부유물 2단계 × 3밴드, 엽록소 3단계 × 3밴드,
풍속 4종, 태양천정각 4종; 방향 8,450개)을 두 방법으로 산출해 OCRT와 맞대었다.
오차는 조합별로 OSOAA 최대 크기로 정규화한 뒤 조합 평균을 취했다.

| 양 | 기존 차감법 (평균 / 최대) | **신규 직접법 (평균 / 최대)** |
|---|---|---|
| Rrs(0⁺) I | 1.577 % / 16.891 % | **0.211 % / 2.580 %** |
| **Rrs(0⁺) Q** | 0.949 % / 13.856 % | **0.351 % / 3.560 %** |
| Rrs(0⁺) U | 0.606 % / 16.502 % | **0.248 % / 2.646 %** |
| rrs(0⁻) I | 0.143 % / 0.791 % | 0.143 % / 0.791 % |
| rrs(0⁻) Q | 0.171 % / 1.834 % | 0.171 % / 1.834 % |
| rrs(0⁻) U | 0.206 % / 1.877 % | 0.206 % / 1.877 % |

- 수면 위 최대 오차가 16.9 %에서 2.6 %로 내려갔다.
- **수면 위가 수면 아래와 같은 수준에 들어왔다.** 차감이 없어졌으므로 두 준위가
  같은 품질의 기준자료가 되었다.
- 수면 아래는 준위 27을 직접 읽어 차감과 무관하므로 값이 바뀌지 않았다. 이는
  수정이 의도한 범위에만 작용했음을 보이는 대조군 역할도 한다.

---

## 7. 요약

기존 방법은 수출광을 **서로 다른 두 물리계의 시뮬레이션 차이**로 추정했다. 그
차이에는 (i) 상쇄에 의한 상대오차 증폭과 (ii) 해수 알베도가 대기 하향장에 미치는
결합 효과가 함께 들어간다. 새 방법은 수출광을 **옳은 물리계 하나의 해 안에서 항으로
분리**한다. 근사가 개입하지 않으므로 두 오차원이 모두 제거된다.

부수적으로 계산량이 조합당 26회에서 1회로 줄어, 방위각을 촘촘히 잡은 전각도 비교가
현실적인 비용이 되었다.
