## atm_reference.csv.gz

해수가 없는 기준 대기(흑색 프레넬 해면)의 전 각도 반사도다. 같은 조건의
결합 실행에서 이 값을 빼면 해수가 더한 몫이 나온다. 편광에서도 세기와
같은 방식으로 뺄 수 있다. 열은 `atm_I`, `atm_Q`, `atm_U` 이며 설계 축과
각도로 맞추면 된다.

편광 반사도는 sqrt(Q^2 + U^2), 선형편광도는 그 값을 I 로 나눈 것이다.

계산을 다시 확인할 때 쓴다.
