## OSOAA 표면 자기 그늘(Sancer) 구현 검증 (2026-08-18, 사용자 요청)

### 구현 검사 (소스·패치 직접 정독)
- 공식: ν=cotθ/σ, Λ=[exp(−ν²)/(ν√π)−erfc(ν)]/2, S_bi=1/(1+Λ1+Λ2) — OSOAA의 σ 규약(SIG=총 평균제곱경사, G=exp(−tan²θN/SIG)/SIG)과 일치하는 정준형이다. 가드(ν>20 컷, sin 하한) 정상.
- 적용 지점: 반사 전용(표면행렬 RAA/RBB + 직달 글린트). 투과 커널 OSOAA_CALC_GT는 의도적으로 무그늘("OCRT direct-transmission parity" 주석)이며, GT 본문에 그늘 곱이 없음을 코드로 확인했다.
- 표면행렬 신선도: 본 E2b 실행들이 패치된 exe로 당일 재생성했음을 타임스탬프로 확인(w7 행렬 08-18 07:08 등) — 구세대 행렬 재사용 아님.

### 결정 논거 1 — 그늘 크기의 해석 상한
- 정준 Λ: 풍3·60°에서 2.2e-11, 풍7·60°에서 9.1e-7, 풍7·70°에서 5.4e-4, 풍7·80°에서 3.9e-2. 즉 우리 검증 기하(VZA≤60°, 풍≤7)에서 그늘 기여는 ≤1e-6으로, 측정 dev_OS(2e-3~8e-3)와 세 자릿수 이상 괴리다. **그늘 구현의 정오와 무관하게, 그늘은 관측된 상향 투과 편차의 원인일 수 없다.** 그늘이 유의해지는 영역은 θ≳70°부터다(비교 캠페인 VZA 상한 60° 규약의 타당성도 함께 확인).

### 결정 논거 2 — 거친면 투과 크기의 독립 물리 검증 (OSOAA 무관 제1원리)
- 표준 마이크로패싯 굴절 BTDF(Walter et al. 2007) + Cox-Munk 법선분포(그늘항 1)를 결정론 구적으로 독립 구현했다. 자기검증: 등방장·σ²=2e-4에서 평면 프레넬 T/n²를 비율 1.0000~1.0002로 재현(정규화·n² 스케일 포함 정확).
- 입력 수중장은 OCRT 순수해수 vza88 실행(θ_w≤48.24°)의 실측 Lu(0−)다.
