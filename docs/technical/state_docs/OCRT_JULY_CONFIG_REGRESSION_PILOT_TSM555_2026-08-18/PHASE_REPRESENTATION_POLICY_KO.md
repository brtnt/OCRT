# OCRT 위상함수 표현 정책 (기본 구현 방식 선언)

작성 2026-08-18 (Jae 지시의 명문화). 이 문서는 OCRT의 위상함수(phase function) 취급에 관한 **절대 규칙**을 선언한다. 코드·자료·검증 게이트의 설계와 변경은 모두 이 정책을 따른다.

## 1. 정책 선언

1. **표준 구현 = 선형 보간(linear interpolation) + 전방 산란 구간 조밀 각도 격자.** 위상함수는 저장된 각도 표를 산란각에 대해 선형 보간해 사용하며, 전방 산란 피크가 해상되도록 각도 격자를 전방 구간에 조밀하게 구성한다(현행 FR631 격자·직접절단(DIRECT_TRUNCATION) 계열이 이 정책의 구현체다).
2. **고차 다차식·모먼트 전개의 사용 확대는 금지한다.** 특히 **그릭계수(generalized/Legendre moments) 차수 L의 상향은 정책상 하지 않는다.** 고차 전개는 유한 절단에 따른 진동(링잉·Gibbs 현상)과 재구성 음수(비물리 위상값)의 잠재위험을 구조적으로 내포하기 때문이다.
3. **새 위상 자료의 검증·채택 판정은 선형 보간 표현을 기준으로 수행한다.** 모먼트 재구성 품질(예: L=200 재구성 음수 여부)은 해당 소비 경로가 모먼트일 때에 한해 부차 게이트로만 쓴다. 원자료가 저장 격자에서 물리적(P11≥0, |P12|≤P11, |P33|≤P11, 정규화)이면 원자료는 건전한 것으로 판정한다.

## 2. 이 정책이 채택된 이유 (역사적 근거)

코드를 선형 보간 방식으로 전면 개편한 근본 이유가 바로 고차 전개의 진동 위험이다. 실측 근거는 다음과 같다.

- **재구성 음수 사례**: 330–1100 nm detritus 확장 후보(`Detritus_Stramski2001_330_1100_CANDIDATE_REJECTED_L200.mie`)는 저장 격자에서 P11≥0 등 물리성 검사를 전부 통과한 **건전한 원자료**였으나, 당시 구성모델 혼합 경로의 L=200 그릭 재구성에서 후방각 최소 P11이 약 **−8.07×10⁻²**로 음수가 되어 SOS가 붕괴했고(수렴 실패·rc 오류), 이 표현 한계 때문에 기각되었다(원전: `DETRITUS_CANDIDATE_DECISION_KO.md`, 2026-08-14).
- **전수 감사 사례**: 2026-08-14 위상 진동 감사(`05_DIAGNOSTICS/OCRT_PHASE_OSCILLATION_AUDIT_2026-08-14/`)에서 에어로졸·EAP·detritus 다수 블록이 원자료는 정상이면서 L 재구성 단계에서 고주파 진동·음수·오차 증폭을 보였다. 즉 문제는 자료가 아니라 **표현(모먼트 절단)** 에 있음이 전 입자군에서 반복 확인되었다.
- **직접절단의 대응**: 전방 피크는 모먼트로 담는 대신 절단(truncation) 후 광학두께 재정규화로 처리하고, 나머지 각 분포는 조밀 격자 선형 보간으로 소비한다. 선형 보간은 비음수 표의 볼록 결합이므로 **구조적으로 음수·진동을 만들 수 없다.**

## 3. 파급 규칙 (실무 지침)

1. **L 상향 금지**: 성능·정합 문제의 해법으로 그릭 차수 상향(예: L=200→400)을 제안·시도하지 않는다. 표현 문제의 정도(正道)는 선형 보간 경로의 정비다.
2. **자료 채택 게이트**: 신규/확장 위상 파일은 (a) 저장 격자 물리성(P11≥0 등), (b) 전방 격자 조밀성, (c) 선형 보간 소비 경로에서의 실전 게이트(기준 케이스 비트·항등식·교차검증)로 판정한다. 모먼트 재구성 게이트 단독으로 원자료를 기각하지 않는다.
3. **잔존 모먼트 경로의 취급**: 구성모델 혼합 등 일부 경로에 남아 있는 L=200 모먼트 사용은 "검증 완료된 현행"으로 유지하되, 그 한계(재구성 음수 가능성)를 신규 자료에 전가하지 않는다. 해당 경로의 장기 방향은 선형 보간 정렬이며, 전환 시 본 정책의 게이트를 따른다.
4. **문서화 의무**: 위상 표현에 영향을 주는 모든 변경은 본 문서를 갱신하고 변경 사유를 기록한다.
