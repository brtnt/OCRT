# 지시서 1 이행 보고 — 천저 극점 해석 극한 병합 (2026-08-18)

## 원인 확정 (구현 전 최종)
- compute_hovenier_rotation(shared/mat3.h)에서 출사 극점 s_out=0일 때 c2 분자·분모가 동시에 정확히 0이 되고 1e-12 분모 가드가 cos i₂=0을 강제한다. 이때 build_rotation_L이 φ-상수 diag(1,−1,−1)로 붕괴해 Q가 전량 m=0으로 유입된다 — 파일럿의 "회전 부재·진폭 과대" 서명과 일치한다.

## 구현
- shared/mat3.h에 compute_hovenier_rotation_cp 신설: 비극점 분기는 기존 본문의 축자 복사(비트 동일 보장), 정확 극점(s==0.0, 극점 노드는 정확 ±1 삽입이므로 판정 정확)에서 해석 극한 적용.
  - 출사 극점: cos i₂ = −μ_out·cosφ, sin i₂ = sinφ (1차 전개 유도, 단위 노름 자동).
  - 입사 극점(대칭): cos i₁ = −μ_in·cosφ, sin i₁ = sinφ.
  - 이중 극점은 P12(0°/180°)=0으로 Q/U 모호성 없음.
- rt_value_phase.c의 수중 편광 값 커널 호출부만 신함수로 교체(스크래치 3곳: pol_rows·solar 매크로·beamq / 정본 2곳: beamq 부재). 기존 함수와 타 사용처(대기 솔버 등)는 무변경.
- μ=±1 해석 분기는 지시서 1 승인으로 각도 분기 금지 원칙의 명시 예외 처리되었다.

## 규약 갱신 (부속)
- 천저 기준면 규약 확정: 출력 재구성에서 Q(vza=0,φ)=−L·cos2φ, U=+L·sin2φ (Fourier: μ=1에서 I는 m=0만, Q/U는 m=2만, 2Q₂=−L, 2U₂=+L). moment 경로·OSOAA와 일치.
- 비교 규약의 "VZA0 Q/U 게이트 금지" 조항 폐지: 향후 파리티·회귀에 천저 셀을 포함하고 G3 구조 게이트(L 상수성·cos2φ 적합)를 상시 편입한다.
