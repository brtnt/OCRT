# 작업 지시서 2 — 종(species) moment 경로 I −0.40% 드리프트 특정·판정

## 확정된 배제망 (본 세션 완료분)
- 자료: red_clay 555 a*·b* 동일(0.0000%), .mie 벌크 ≤0.005%.
- 로더+자료 블록: [7월 솔버+현재 AHN 로더+현재 FR631 자료] = 7월 순정 +0.0004% 상수.
- 대기·결합: 무대기에서도 +0.40% 유지. 고정 IOP 경로: 절제 B0→B2 = 0%.
- 파라미터 기본값: moment mode=1(gauss)·nmg=400·Lmax(경로기본 200) 양 시대 동일.
- 혼합 호출부·후처리 블록: diff 상 실질 동일. pol-SS: 양 시대 공존으로 배제.
- 잔여 용의 구간: water_mixed_phase_cache_load 캐시 미스 시 호출되는 컴포넌트 모멘트 projector 함수 본문, 그리고 종 경로 한정으로 타는 그릭 커널 조립 진입부.

## 1단계 — 함수 단위 특정 (코드 무수정, 스크래치 교차 빌드)
- 7월 트리 사본에 현재의 후보 함수를 1개씩 이식·빌드·무대기 케이스 실행:
  (a) 컴포넌트 모멘트 projector(3262행 water_mixed_phase_cache_load가 미스 시 호출하는 함수 — 정확 명칭은 본문에서 특정),
  (b) 그릭 커널 조립 진입 함수.
- +0.40%를 재현하는 이식이 원인 함수다. 예상 빌드 2~3회, 각 실행 수 초.

## 2단계 — 판정
- 원인 함수의 7월↔현재 diff와 주석(커밋 태그)을 정독해 변경 의도를 분류한다.
- 의도 변경(개선)인 경우: 참조 기준으로 정확도 판정 — L→∞ 모멘트 재구성 대 .mie 각도표 정확 적분(bb/b 포함)을 수치 기준으로 두고, 7월판·현재판 중 참조에 가까운 쪽을 채택한다. 채택 결과가 현재판이면 −0.40%는 "의도 개선"으로 문서화하고 7월 기준선을 갱신한다.
- 비의도 회귀인 경우: 수정 패치를 별도 지시서로 상정한다(본 지시서에서 코드 수정 없음).

## 게이트
- 전 과정 정본 무수정, 스크래치 한정. Tier-0 앵커 유지 확인.
- 종결 조건: 원인 함수 1개 특정 + 판정 문서(회귀/개선) + 필요 시 수정 지시서 초안.

## 부속 미규명(기록)
- 7월 재빌드 대 7월 보관값의 셀별 산포 ±0.5~0.7%(중앙 0)는 7월 캠페인 실제 옵션과의 미세 차이로 추정되며, 원인 특정은 본 지시서 범위 밖으로 둔다.
