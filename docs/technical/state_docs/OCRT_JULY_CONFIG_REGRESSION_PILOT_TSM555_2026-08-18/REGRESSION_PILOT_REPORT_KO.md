## 판정
1. 비커널 수정 전체(moment 경로): Q/U/DoLP는 7월 기준선과 동급 이상으로 재현된다. 단 **I가 −0.40% 균일 드리프트**(현재/7월OCRT 비 0.99596)했다. 의도 변경 예산(≤0.1%)을 초과하는 미규명 항목이며 후속 격리가 필요하다. 후보: FR631 red_clay 자료(절제는 Brown_earth만 측정), mie_io/ahn 로더 변경, surface 캐시화, 대기 기본값. 규모상 Brown-earth 잔차(1.45%)의 주인은 아니다.
2. **direct(생산) 모드 천저 Q 결함 — 신규 발견**: VZA=0 13셀에서만 Q 편차 최대 23.3%/DoLP 23.8pp(라아 0/180에서 최대, 라아에 따라 감쇠). VZA>0에서는 Q/U 정상(≤0.11%). moment 경로는 천저 정상이므로 값 커널의 천저 Q 회전/극한 처리 결함으로 국소화된다. 기존 "VZA0 Q/U 게이트 금지" 규약과 풍속 0 위주 진단 때문에 잠복해 온 항목이다.
3. 격자 결론과의 관계: 본 구성은 τ=16.6(<30)이라 OSOAA 격자 상한 미발동 영역이며, 격자 판정과 독립적인 회귀 검사다. Brown-earth 1.45% 잔차의 격자 귀속 결론은 유지된다.
