- 직전 판정의 근거였던 파이썬 facet 모델에 half-vector 구성 오류(−(n·u_w+u_a) 사용)가 확인되었다. 정확 Walter 규약(h ∝ n·u_w − u_a; 분모는 η 합 항등식으로 ‖N‖²=n²+1−2n·cosΨ로 붕괴)으로 완전 재구축한 py''는 **C 커널과 a20 정점 프로파일 전 점에서 C/py''=1.000(4자리) 완전 일치**했다.
- 판정: **surface_T_coxmunk_trig(wa)는 정확 Walter facet BTDF다 — 무죄.** 승인된 2단계 커널 수정을 중단한다. 구 py로 산출한 "facet 목표 dev −0.212%(20°)"는 무효로 폐기한다(등방 극한 통과는 규약 대칭성에 의한 우연 — 극한이 h 규약을 판별하지 못함을 기록). py'' 반구 적분 파이프라인의 별도 버그([A]/[D] 0 수렴)는 판정과 무관하며 후속 정리 항목이다.

### 재구성된 문제 구도
- P2b(복원 rough 결합)는 정확 커널의 올바른 적용이므로, dev_OC(−0.034%@20° ~ −0.345%@60°)가 **Walter/Cox-Munk 물리의 참값 후보**다.
- 열린 질문은 역전된다: OSOAA의 dev_OS(−0.209~−0.526%)가 왜 더 어두운가 — 후보 (a) OSOAA 거친면 투과 연산자의 로브가 Walter보다 넓음(그들 구성 차이), (b) dev_OS 측정의 오염(수중 −0.26% 오프셋의 VZA 형상 성분은 0.056%p로 부분 기여 가능, 잔여 미설명), (c) 추출 보간.
- 다음 결정 실험: **OSOAA SURF_MATR의 T_wa 행렬 직독** — 같은 (μ_a, μ_w)에서 OSOAA 연산자 로브를 추출해 Walter(=C=py'')와 대조한다(v1.10 미완 항목의 이행). 로브가 넓으면 (a) 확정 — 이 경우 "개선 대상"의 소재가 OCRT에서 OSOAA로 역전된다. 같으면 (b)(c) 계열 정밀 조사로 이행한다.

## SURF_MATR 직독 판정 — 연산자 동일성 확정 (2026-08-18, v1.10 미완 항목 이행)

### 방법
- OSOAA는 TWA 파일을 별도 저장하지 않고 TAW 행렬 파일을 FICTWA로 재사용함을 확인(OSOAA_SOS.F 1646~1683). TAW-…-RadMU96(풍3) 언포맷 파일을 직접 파싱: 레코드 352,836B = 9성분×99²(가우스 96+특수 3)×4B, IS=0..200 총 201레코드, 첫 레코드가 m=0. 축 규약은 데이터로 판독(비영 원소 스넬 비 1.334): [수중, 공기]. 각도·가중은 RAD_UsedAngles(D-지수 표기 처리).

### 판정
1. **형상 동일**: 공기 μ=0.9377 열의 정규화 프로파일이 Walter(=OCRT C 커널=py'')와 전 점 3~4자리 일치, 반치폭 a20 0.0128=0.0128, a60 0.0641=0.0641. 절대비 5.11 균일(스케일 규약 상수, 물리 무관). → **OCRT wa 커널 ≡ OSOAA TAW 연산자.**
2. **적용도 정확**: OSOAA 절점(가우스 가중) 표본합 대 조밀 적분의 순수 구적오차 = 0.000%(MU48/96, vza 20/40/60). 중간 산출의 +3~14%는 본 분석의 로그-보간 아티팩트였음을 정정 기록한다(가우스 구적은 보간 곡선이 아니라 표본 다항의 적분).
3. 따라서 dev_OC(−0.034~−0.345%)와 dev_OS(−0.209~−0.526%)의 0.17~0.18%p 차이는 투과 연산자·적용 어디에도 존재하지 않으며, **소재는 dev 측정 사슬의 계면 밖 성분** — 두 코드 수중장의 기지 불일치(TODO 1: −0.24~−0.29%, VZA 의존)와 추출 사슬(WL 재구성/level-27 보간) — 로 귀속된다. "항 B"는 계면 항목으로서는 소거되고 TODO 1로 통합한다.
