## 2. 무엇이 어떻게 어긋났나 (경위)

### 2.1 VZA 앵커 — 지시서 기하를 그대로 따른 초판이 틀렸다

지시서 §1.3 은 원점 지구중심, z축이 TOA 센서점 A 를 지나는 좌표에서 시선을 r_B = r_A − dV 로 정의한다. 이 정의에서
θ_v 는 **TOA 에서의 국소 천정각**이다. 초판 구현은 이를 그대로 따랐고, 사용자 지정 스윕(VZA 55, RAA 90)에서 태양이
천정에 있어도 IPSS/무보정 비가 κ = 1.028(VZA 55), 1.11(VZA 70) 로 남았다. 사용자가 "SZA 65° 미만에서는 차이가 거의
없어야 한다" 고 지적해 추적한 결과:

- 구면에서 직선 광선의 국소 천정각은 sin θ(r)·r = const 로 고도에 따라 줄어든다(화소 55° → 100 km 에서 53.755°).
  평면평행 해는 μ_v 를 모든 고도에 같은 각으로 쓰므로, κ 의 분자·분모가 **같은 기하를 공유하는 고도**를 정해야 한다.
- 지상 앵커: 대기 질량이 있는 고도에서 두 기하가 일치 → 대기를 지표로 붕괴시키면 κ→1 (척도높이 8→0.1 km 에서
  −0.24 → −0.004 %), 모델 TOA 높이 H 에 무관(H 60–200 km 에서 −0.24 % 고정).
- TOA 앵커: 붕괴 극한에서도 +2.85→+3.11 % 잔존, H 에 비례 발산(+0.67 → +6.30 %, H 30→200 km). 센서 고도는 어디에도
  들어가지 않는다(정지궤도 실제 기하 검산: Δθ 는 senz 만의 함수).
- RTSOS(저자 코드) 기본값 `IPSS_VIEWANGLE_GROUND=0`(지상), 저자 주석 "1 = Korkin 벤치마크용". 논문 균질 케이스가 TOA
  규약인 것은 벤치마크 관례이지 위성 자료 규약이 아니다.

지시서는 이 규약을 "비교 전 명시" 로만 다뤘고 구현 기본값을 지정하지 않았다. **v1.1 에서는 §1.3 첫머리에 "생산 기본 =
지상 화소 앵커, TOA 앵커는 벤치마크 재현 분기" 를 규정**해야 한다.

### 2.2 위상함수 가중 — 지시서는 옳았고 구현이 떨어뜨렸다

지시서 §2 단계 2 의 S₁ 에는 P(Θ) 가 있다. 그러나 "cos Θ = V₀·V 는 전역 상수" 라는 서술과 Rayleigh 단독 참조 구현(P
없음)이 겹쳐, 구현은 "Θ 가 일정하므로 P 가 분자·분모에서 상쇄된다" 고 일반화해 층 원천을 β_j·ω_j 로 두었다. 이 상쇄는
**단일 산란체 또는 혼합비가 고도에 무관한 대기에서만** 성립한다. 운영 대기(에어로졸 2 km / Rayleigh ~8 km)에서는
측·후방 산란각에서 P_A/P_R ≈ 0.1 이라 단일산란은 Rayleigh 층이 지배하고, 미가중 κ 는 저고도 에어로졸 층을 8–10 배
과대 가중했다. 크기: VZA 55 / RAA 90 / AOD 0.1 에서 저 SZA 0.03–0.09 %p, SZA 85 에서 0.6–1.9 %p(555 nm: +13.80 →
+11.91 %). RTSOS 는 구면 단일산란 재귀 안에서 층별 위상행렬(`PHASE_MATRIX_CALC`)을 곱하므로 논문 정의 그대로다.

수정(v1.11.1): `rt_ipss_t` 에 층별 산란분율과 P_R(depol)·P_A(FR631 값표 우선, Legendre 대체)를 싣고 기하마다
w_src,j 를 구성. Rayleigh 단독은 비트 동일. 검증 G-I4a(혼합비 고도-일정 시 미가중과 2.4e-15 로 동일), G-I4b(2성분
합성 프로파일 7개 기하에서 독립 scipy 적분과 |Δκ| ≤ 7.5e-6). **v1.1 에서는 §2 단계 2 에 "혼합 대기에서 P 는 상쇄되지
않는다 — 층별 w_R P_R + w_A P_A 가중 필수, SOS 와 같은 위상함수 표현(값 커널) 사용" 경고를 넣고, 참조 구현에 2성분
테스트를 추가**해야 한다. Rayleigh 단독 교차검증은 이 결함을 원리적으로 잡을 수 없다는 점도 적어 두는 것이 좋다.

### 2.3 legacy 삭제 — 사용자 결정

지시서 §3 의 `--pssa-mode` 병존 권고는 옵션 정책(2026-08-21) 준수 차원에서 합리적이었으나, 사용자가 혼란 방지를 위해
legacy 를 **소스 트리에서 삭제**하도록 지시했다. 결과적으로 `rt_options_t.pssa_mode`, `rt_atm_t.pssa_*`,
`rt_surface_boundary.c` 의 PSSA 분기, `rt_pssa.{c,h}` 가 제거됐고 비-PSSA 경로는 삭제 전후 비트 동일하다. 삭제
파일은 `validation/ipss_2026-09-05/removed_legacy/` 에 보존. 과거 `--pssa` 캠페인 산출물(legacy + TOA 앵커)의
재실행 판정은 미결(SZA 75° 이상 슬롯이 실질 영향권).

### 2.4 Korkin 대신 RTSOS

Korkin et al. (2020) 공개 데이터는 입수하지 않았다. 대신 저자 참조 코드 RTSOS 를 gfortran 으로 빌드해 동봉 Coulson
벤치마크를 재현(I 상대차 3.5e-4)한 뒤, 같은 층 프로파일(지수 8 km, τ 0.0935, 등-Δτ N층)에서 κ 를 대조했다.
인공항 보정 후 |κ_RTSOS/κ_OCRT − 1| ≤ 0.105 %(SZA 40–85 × VZA 0–70 × φ 0/90/180, 두 앵커 분기), 층수 1/N 외삽값은
VZA 55 에서 −0.239 % vs OCRT −0.240 %. 참조 패키지 발행 세션이 알아야 할 RTSOS 측 사항:

- `main.f90` 의 `fSnowBRDF_INPUT`/`fRossLiBRDF_INPUT` 미초기화 — `-O2` 에서 .TRUE. 로 읽혀 입력 EOF 로 죽는다.
- 동봉 Makefile 의 `-llapack -lblas` 가 오브젝트 앞에 있어 링크 실패.
- IPSS 모드는 천저에서도 SZA 무관 옵셋 **정확히 exp(−Δτ_layer) − 1** 을 남긴다(N=10/40/160 → −0.928/−0.233/−0.058 %).
  NHEIGHTINT·Δτ 적분 간격과 무관한 층 이산화 인공항이며, 참조값으로 쓸 때는 나눠 내거나 층수를 늘려야 한다.
- SZA = 0 정확히에서 NaN(sin θ₀ = 0 특이). 방위 매핑 φ_RTSOS = 180° − raa_OCRT.
- RTSOS 는 CC BY-NC 4.0 — 파생 파일 재배포 시 출처·변경 표시 필요(공개 저장소에는 NOTICE 를 붙여 두었다).

### 2.5 지시서 §0 배경의 오차 귀속

"경사 관측에서 −16 %~+5 %" 는 논문이 정의한 PSS(구면 시선 + 천저축 태양경로)의 오차다. OCRT legacy 는 시선을
평면평행으로 두고 태양 직달빔만 Chapman 평균할선으로 고쳤으므로 다른 알고리즘이고, 실측 오차는 훨씬 작다(τ=0.25:
−0.3..+3 %, τ=1.0: −1..+7 % @ SZA 84.26). legacy 의 실제 한계는 크기가 아니라 **방위 의존성의 부재**(글린트 반평면에서
양, 반대에서 음으로 갈리며 VZA 와 함께 커짐)다. 배경 서술을 이렇게 바꿔야 나중에 논문 §4.4 서술과 어긋나지 않는다.
초판 기록이 두 오차를 동일시했던 것도 같은 원인이었고 폐기했다.
