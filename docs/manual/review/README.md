# 실행 예시 검토 목록

검토 기준일: 2026-09-12

기존 40개 레시피 중 처음 사용하는 사람이 계산 흐름과 결과를 확인하는 데 필요한 **10개를 유지하고, 나머지 30개는 검토 대기로 보류**한다. 선정 기준은 기본 대기·해양 계산, OCRT의 RAA와 편광 부호, 에어로졸 기준 파장, 수질 구성성분과 전체 IOP 입력, LUT·배치 출력, 수치 수렴을 적은 수의 예시로 이어서 익힐 수 있는지이다. 보류 예시는 삭제하지 않고 원본을 보존하며, 기본 예시와 겹치는 변형이나 별도 해석이 필요한 진단 사례부터 검토한다.

현재 기본 목록은 **R01, R02, R07, R21, R26, R28, R36, R38, R39, R40**이다. 모두 실행하면 **10개 레시피, C 실행 파일 13회 호출**이며, R39가 3회, R40이 2회, 나머지 8개가 각각 1회이다. R39의 배치 호출 한 번에는 두 파장 상태가 들어간다.

보류한 30개는 기본 실행 목록이나 매뉴얼에 **자동으로 복원하지 않는다**. 필요성·중복·해석상의 한계를 검토한 뒤 개별적으로 추가한다. R01–R40 번호는 이전 문서, 결과 파일, 검증 기록과의 대응을 유지하기 위해 보존하며, 현재 매뉴얼의 번호 사이에 빈 구간이 있는 것은 의도한 구성이다.

## 40개 레시피의 목적과 상태

표의 비교 대상은 보존된 원본에 따른다. 보류 예시가 다른 보류 예시를 기준으로 삼는 경우에는 함께 검토한다. I/Q/U는 Stokes 성분, AOD는 에어로졸 광학두께, IOP는 고유광학특성을 뜻한다.

| R10 | SZA=VZA=40°, RAA 180°의 거친 해면에서 직달 선글린트를 포함한 TOA 반사도를 계산한다. | 보류 | R11과 함께 유지 여부를 검토한다. 두 예시의 총출력 차이로 직달 항을 비교한다. |

| R16 | R07의 기체 0 지정을 제거하고 `usstd76`의 기본 여섯 기체 총량으로 555 nm 흡수를 계산한다. | 보류 | 기본 기체 입력 시연이다. 기체별 총량을 로그와 함께 보관하며, 예전 배치 경로에 같은 기체 초기화를 가정하지 않는다. |
