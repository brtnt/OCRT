\chapter{C 내부 환경변수 소스 색인}
\label{chap:03_environment_index}
매뉴얼 목차 · \hyperref[chap:03_options]{일반·고급 옵션 설명}

이 부록은 2026-09-11 기준 \texttt{code/\allowbreak{}OCRT\_\allowbreak{}C/\allowbreak{}src}에서 문자열 이름으로 \texttt{getenv()} 또는 DEBUG 게이트 함수 \texttt{ocrt\_\allowbreak{}debug\_\allowbreak{}env()}를 호출하는 위치를 기계적으로 추출한 개발·재현성 점검용 색인이다. 환경변수 값을 읽거나 사용자의 현재 환경을 수집한 목록이 아니다. 같은 이름이 여러 파일에서 사용되면 파일마다 첫 위치를 연결한다.

일반 사용자는 옵션 장에서 설명한 운영 변수만 사용한다. 이 표에 있다는 사실은 공개적으로 지원되는 물리 모델이나 권장 설정이라는 뜻이 아니다. 내부 실험·프로파일링·진단 항목에는 읽기 위치, 값의 허용 범위, DEBUG 게이트, 결과에 미치는 영향을 확인하는 과정이 필요하다. 일부 변수는 값과 무관하게 존재 자체로 켜지며, \texttt{0}으로 설정하는 것과 변수를 제거하는 것은 다를 수 있다.

OpenMP가 읽는 \texttt{OMP\_\allowbreak{}NUM\_\allowbreak{}THREADS}는 C 소스의 직접 getter 목록 밖에 있다. 이 색인은 명시된 두 getter의 문자열 호출만 포함하며, 외부 라이브러리의 환경변수는 해당 라이브러리 문서를 확인한다.

직접 이름을 읽는 변수 \textbf{149개}의 색인이다.
