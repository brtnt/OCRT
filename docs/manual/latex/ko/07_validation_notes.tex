전체 C 파서의 인식 이름 \textbf{168개}가 \hyperref[chap:03_options]{\ref*{chap:03_options}장}에 포함되는지 추출 목록으로 검사했다. 일반 옵션 외의 별칭·호환·진단 이름도 포함한 수다. C 환경변수 \textbf{149개}는 별도 소스 색인에 실었다. Python 주요 계산·캠페인 CLI의 옵션도 파서와 대조했고, 예제 상태표의 6행이 두 입력 리더에서 해석됨을 확인했다.

이 확인은 설치·예시·문서 형식의 확인이다. 모든 옵션의 물리 효과를 조합별로 실행했다는 뜻은 아니다. 전체 센서 격자, 모든 Mie 모델, 모든 파장과 고농도 상태를 생산 검증한 결과도 아니다. 예시의 다른 파장·농도·각도, Windows 네이티브 재빌드, 전체 IPSS 회귀 스크립트의 이번 실행은 위 표의 확인 범위에 포함되지 않는다. Python 성분 배치는 아래 EAP 자료 제한으로 수치 실행을 확인하지 못했다.

\section{그림과 핵심 예시의 검증 기록}
\label{sec:auto:07_validation_notes:6}
부록~\ref{chap:09_cookbook}은 핵심 예시 10개, C 명령 13개로 구성한다. 명령은 2026년 9월 11일의 실행 기록에서 변경 없이 선별했다. 출력 구조·주요 수치의 유한성·해당 수렴 표시를 확인했고, R39의 개별·배치 실행은 두 파장에서 모든 CSV 필드가 같았다. 현재 요약은 \path{examples/verification_core_examples.json}, 실제 C 방위각 그림의 자료는 \path{latex/figures/data/}에 있다.

이 검사는 모든 조건의 물리적 정확도를 보증하지 않는다. 과거 강한 기체흡수 검사에서는 수렴 표시가 1이어도 대기층 수에 민감한 결과가 있었다. 원본 40개와 과거 진단은 \path{review/}에 보관한다. 실제 활용 조건에서는 해상도 수렴과 기준 자료 비교를 별도로 수행한다.
