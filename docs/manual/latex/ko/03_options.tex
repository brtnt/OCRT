\section{입력 규칙과 실행 모드}
\label{sec:auto:03_options:1}
명령은 \texttt{code/\allowbreak{}OCRT\_\allowbreak{}C} 디렉터리에서 실행한다. 옵션과 값은 공백으로 나눈다. 예를 들어 \texttt{-\allowbreak{}-\allowbreak{}wavelength 443}이며, \texttt{-\allowbreak{}-\allowbreak{}wavelength=\allowbreak{}443} 형식은 지원하지 않는다. 경로에 공백이 있으면 경로 전체를 따옴표로 감싼다. 값은 대소문자를 구분한다. 숫자는 소수점 \texttt{.\allowbreak{}}과 지수 표기(\texttt{1e-\allowbreak{}7})를 사용한다.

파서는 모든 숫자의 문법·유한성·물리 범위를 엄격하게 검사하지 않는다. 아래에서 제시한 물리 범위와 단위를 지키며, 숫자 자리에는 \texttt{NaN}, 무한대, 단위 문자열을 넣지 않는다. 인자를 인식했다는 사실만으로 물리적으로 유효한 실행이 보장되지는 않는다.

단일 기하와 격자·배치 지시는 함께 쓸 수 없다. \texttt{-\allowbreak{}-\allowbreak{}vza} 또는 \texttt{-\allowbreak{}-\allowbreak{}raa}만 하나 지정하면 오류다. \texttt{-\allowbreak{}-\allowbreak{}batch}와 \texttt{-\allowbreak{}-\allowbreak{}batch-\allowbreak{}full-\allowbreak{}grid}도 배타적이다. 해양의 \texttt{-\allowbreak{}-\allowbreak{}water-\allowbreak{}model}은 정확히 한 번 지정하고, 선택한 모델과 다른 접두사의 수질 옵션을 섞지 않는다.

\texttt{-\allowbreak{}-\allowbreak{}batch}는 별도 대기 사례 경로다. 특히 현재 \texttt{main.\allowbreak{}c}에서는 기체흡수 초기화보다 먼저 이 경로로 반환한다. 따라서 일반 단일/격자 실행의 기체흡수 기본값과 기체 컬럼 지정이 \texttt{-\allowbreak{}-\allowbreak{}batch}에도 적용된다고 가정하지 않는다. 기체흡수를 포함한 대기 자료는 단일 기하 또는 각도 격자 명령을 반복 실행한다. 배치 CSV의 정확한 열과 제한은 출력·파일 형식 장을 참고한다.

\textbf{단위 정정:} 기존 도움말과 표준오류 로그의 \texttt{mol/\allowbreak{}cm\textsuperscript{2}} 표기는 몰수가 아니라 \textbf{분자수/cm\textsuperscript{2}}를 뜻한다. 실제 H\textsubscript{2}O 변환은 \texttt{G \ensuremath{\times} 6.\allowbreak{}02214076e23 /\allowbreak{} 18.\allowbreak{}01528}이다. O\textsubscript{2}·CO\textsubscript{2}·CH\textsubscript{4} 입력에 mol cm\textsuperscript{-}\textsuperscript{2} 값을 넣으면 아보가드로 수만큼 잘못된 입력이 된다.

단일/격자 실행에서 기체흡수는 기본 활성이다. 순수 Rayleigh 기준 계산에는 다음 여섯 값을 모두 명시한다.


\begin{ManualCode}
--gas-column-h2o 0 --gas-column-o3 0 --gas-column-no2 0 --gas-column-o2 0 --gas-column-co2 0 --gas-column-ch4 0
\end{ManualCode}

각 기체의 기본 컬럼은 프로파일과 배포 데이터에 의존한다. 실제 로그의 \texttt{column=\allowbreak{}} 및 \texttt{overridden} 표시를 기록한다. 음수는 내부에서 미지정 표지처럼 취급될 수 있으므로 흡수 OFF 용도로 사용하지 않는다. 사용자 프로파일은 \texttt{inputs/\allowbreak{}afgl\_\allowbreak{}atm/\allowbreak{}afgl\_\allowbreak{}userdef.\allowbreak{}dat}에 두며 \texttt{-\allowbreak{}-\allowbreak{}atm-\allowbreak{}profile userdef}로 선택한다. \texttt{-\allowbreak{}-\allowbreak{}atm-\allowbreak{}profile}은 기체 프로파일 선택이며 Rayleigh 분자 대기 자체를 일곱 종류 중 고르는 옵션은 아니다.

기준 파장을 혼동하지 않도록 AOD 입력 방식은 한 종류만 사용한다. 여러 \texttt{-\allowbreak{}-\allowbreak{}aod-\allowbreak{}*}를 함께 쓰면 파싱 순서에 따라 AOD 값과 기준 파장이 바뀐다. 예를 들어 \texttt{-\allowbreak{}-\allowbreak{}aod-\allowbreak{}555 0.\allowbreak{}1 -\allowbreak{}-\allowbreak{}aod-\allowbreak{}ref-\allowbreak{}wavelength 865}는 최종적으로 865 nm 기준 AOD 0.1이 된다.

비배치 실행에서 AOD가 0이면 \texttt{-\allowbreak{}-\allowbreak{}mie}, \texttt{-\allowbreak{}-\allowbreak{}aer-\allowbreak{}h-\allowbreak{}km}, \texttt{-\allowbreak{}-\allowbreak{}aer-\allowbreak{}l-\allowbreak{}max}와 절단 관련 에어로졸 옵션을 함께 지정할 수 없다. AOD>0에서 기본 선택은 value 커널, 실각도 log10-linear 전방 피크 절단, \texttt{L=\allowbreak{}80}, 대기 Fourier \texttt{m=\allowbreak{}16}, 대기 400층이다. 이 에어로졸 기본 절단은 수중 입자의 FR631 기본 절단 OFF 정책과 구분한다.

\texttt{T50}, \texttt{C50}, \texttt{M80C}는 코드가 안내하는 공식 검증 하위 집합이다. 파일명에 \texttt{M50C}가 포함되면 현재 파서는 \texttt{OCRT\_\allowbreak{}DEBUG=\allowbreak{}1}을 요구하고 진단용 경고를 낸다. 해당 모델의 계보 문제는 \href{https://github.com/brtnt/OCRT/blob/54861c68e35ec5aaa3938fad53e93dc2dfa7eb1d/code/OCRT_C/inputs/deprecated/DEPRECATED_M50C.md}{M50C 기록}을 참고한다.

\texttt{-\allowbreak{}-\allowbreak{}lut-\allowbreak{}vza-\allowbreak{}max DEG} & 기본 \texttt{85\textdegree{}} & 출력 VZA 상한. 물리적으로 \texttt{0<값<90}. 해양 경로에서는 범위 밖 값이 85로 대체되므로 잘못된 입력이 항상 오류가 되는 것은 아니다. \\

\texttt{-\allowbreak{}-\allowbreak{}batch-\allowbreak{}full-\allowbreak{}grid FILE} & 기본 없음 & 해양 각도 격자 배치. 한 입력 행의 조건으로 하나의 전체 격자 파일을 만든다. 빈 셀은 CLI 기본을 계승한다. \\
\texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}advanced} & 기본 OFF & \texttt{-\allowbreak{}-\allowbreak{}batch} CSV에 기준값 대비 오차, 산란 차수, 수렴·시간 등의 상세 열을 추가한다. 일반 해양 격자의 60열 형식을 바꾸는 옵션은 아니다. \\

현재 균일 해양 격자에서 VZA는 \texttt{0,\allowbreak{} step,\allowbreak{} \ldots{},\allowbreak{} floor(max/\allowbreak{}step)\ensuremath{\times}step}이다. RAA 개수는 \texttt{floor(360/\allowbreak{}step+0.\allowbreak{}5)}이며, 값은 \texttt{0,\allowbreak{} step,\allowbreak{} \ldots{}}로 생성하고 360\textdegree{}를 중복 포함하지 않는다. 예를 들어 VZA 간격 15\textdegree{}, 상한 85\textdegree{}이면 마지막 VZA는 75\textdegree{}다.

\textbf{명시적 파일 지정을 권장하는 이유:} 현재 \texttt{main.\allowbreak{}c}는 \texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}full-\allowbreak{}grid}를 파싱했을 때 수중 구적 수를 96으로 높인다. 단지 VZA/RAA를 생략해서 뒤늦게 자동 격자 모드가 된 경우에는 이 승격 단계가 이미 지났을 수 있다. 과학 자료 생성 명령에는 항상 \texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}full-\allowbreak{}grid FILE.\allowbreak{}csv}를 넣고, 비교 실행의 수중 구적 수를 기록한다.

\texttt{-\allowbreak{}-\allowbreak{}batch}와 \texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}full-\allowbreak{}grid DIR} 조합은 레거시 배치 부가 LUT 경로에서 후자를 \textbf{파일이 아닌 출력 디렉터리}로 해석한다. 일반 파일 출력과 의미가 다르므로 대기 LUT 제작에는 독립 각도 격자 실행을 권장한다.

\item \texttt{-\allowbreak{}-\allowbreak{}use-\allowbreak{}absorption}, \texttt{-\allowbreak{}-\allowbreak{}afgl-\allowbreak{}dir}, \texttt{-\allowbreak{}-\allowbreak{}xsec-\allowbreak{}dir}: 기체흡수는 일반 실행에서 기본 활성이고 입력 디렉터리는 고정이다.
\item \texttt{-\allowbreak{}-\allowbreak{}water-\allowbreak{}aw-\allowbreak{}lut}, \texttt{-\allowbreak{}-\allowbreak{}water-\allowbreak{}psi-\allowbreak{}T-\allowbreak{}lut}, \texttt{-\allowbreak{}-\allowbreak{}f-\allowbreak{}sun}: 배포 순수 해수 입력과 내부 태양 정규화 규약을 사용한다.
\item \texttt{-\allowbreak{}-\allowbreak{}trunc-\allowbreak{}aer-\allowbreak{}loglin}, \texttt{-\allowbreak{}-\allowbreak{}aer-\allowbreak{}phase-\allowbreak{}kernel}, \texttt{-\allowbreak{}-\allowbreak{}no-\allowbreak{}aerosol}: 양수 AOD의 자동 에어로졸 설정을 사용하고, 비활성은 AOD 0이다.
\item \texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}mode}, \texttt{-\allowbreak{}-\allowbreak{}lut}, \texttt{-\allowbreak{}-\allowbreak{}lut-\allowbreak{}output}: 현재 출력 방식은 \texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}advanced}, 각도 생략에 의한 격자 선택, \texttt{-\allowbreak{}-\allowbreak{}output-\allowbreak{}full-\allowbreak{}grid}다.
\item \texttt{-\allowbreak{}-\allowbreak{}tau-\allowbreak{}r}, \texttt{-\allowbreak{}-\allowbreak{}tau-\allowbreak{}r-\allowbreak{}from-\allowbreak{}input}, \texttt{-\allowbreak{}-\allowbreak{}with-\allowbreak{}rayleigh}: Rayleigh 광학두께는 \texttt{-\allowbreak{}-\allowbreak{}pressure}와 내부 모델에서 산출한다. 현재 호환 \texttt{-\allowbreak{}-\allowbreak{}no-\allowbreak{}rayleigh}/\texttt{-\allowbreak{}-\allowbreak{}rayleigh}와 혼동하지 않는다.
\item \texttt{-\allowbreak{}-\allowbreak{}view-\allowbreak{}as-\allowbreak{}node}, \texttt{-\allowbreak{}-\allowbreak{}vector}, \texttt{-\allowbreak{}-\allowbreak{}no-\allowbreak{}decouple-\allowbreak{}sunglint}: 단일 기하의 관측 노드와 벡터 계산은 기본 동작이며, 일반 경로의 직달 글린트 포함이 기본이다.
\end{itemize}

\section{이 장의 소스 확인 범위}
\label{sec:auto:03_options:12}
옵션 이름은 \texttt{main.\allowbreak{}c}의 인자 루프에서 \texttt{strcmp(a,\allowbreak{}".\allowbreak{}.\allowbreak{}.\allowbreak{}")}로 비교하는 이름을 전수 추출했다. 총 \textbf{168개}이며, 별칭과 명시적으로 거부하는 과거 이름을 포함한다. 위 표는 이 168개를 모두 포함한다. 실행 의미는 \texttt{rt\_\allowbreak{}solver.\allowbreak{}c}, \texttt{rt\_\allowbreak{}water\_\allowbreak{}rt.\allowbreak{}c}, \texttt{rt\_\allowbreak{}absorption.\allowbreak{}c}, \texttt{rt\_\allowbreak{}atm.\allowbreak{}c}, \texttt{rt\_\allowbreak{}ipss.\allowbreak{}c}, \texttt{shared/\allowbreak{}surface.\allowbreak{}c} 등에서 교차 확인했다.

이 문서는 수치 옵션의 모든 조합을 새롭게 과학 검증했다는 뜻은 아니다. 과거 도움말과 실제 코드가 어긋나는 항목은 동작을 숨기지 않고 설명했으며, 재현 가능한 기본 명령과 출력 확인 방법은 부록~\ref{chap:04_examples}를 따른다.
