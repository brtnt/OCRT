\chapter*{이 매뉴얼에 대하여}
\addcontentsline{toc}{chapter}{이 매뉴얼에 대하여}
OCRT는 해색 대기보정과 대기--해양 복사전달 시뮬레이션을 위한 코드다. 본문은 OCRT의 개념, 설치, 옵션, 입력 형식과 출력 해석을 설명한다. 앞부분의 Quick start로 첫 계산을 확인할 수 있다. 상세 활용 예시, LUT 제작, 시뮬레이션 자료 생성, Python 및 보조 코드의 사용법은 부록에서 다룬다.

문서 기준은 2026-09-11의 C 문서 릴리스 v1.11.1이다. 기준 소스 커밋은 다음과 같다.

\texttt{54861c68e35ec5aaa3938fad53e93dc2dfa7eb1d}

실행 파일의 버전 문자열만으로 최신 소스 여부를 판정하지 않는다. Python 지원 범위는 C와 별도로 설명한다.

\textbf{OCRT의 RAA=180도는 선글린트 가지다.} 위성 방위각 변환과 편광 U 부호는 \ref{chap:01_concepts_geometry}장을 먼저 읽고 확인한다. 대기보정용 Rayleigh LUT는 기체흡수, 에어로졸 및 직달 선글린트 포함 여부를 먼저 결정한다.

이 문서는 현행 구현을 설명한다. 기본값과 실제 효과가 다른 과거 도움말, 지원되지 않는 조합, 검증하지 않은 조건은 해당 장에서 구분한다. 예시 실행의 성공은 전체 생산 격자의 과학적 정확도를 보증하지 않는다.
