# Rrs Q 오차 특성·truncation 정합성 판정 (2026-08-23)

조건: 555 nm, SZA 40°, 풍속 3 m/s, red_clay TSM 0.5 + pure 대조, 156기하. 데이터: Q_diagnosis_156.csv.

## 1. truncation 판정 — 실효적으로 동일(양쪽 모두 무절단)

- OCRT: raw FR631 위상 직접 소비(`--ocrt-mie-truncation` 미사용, 08-21 canonical 정책).
- OSOAA: hydrosol 강제절단 코드는 존재(OSOAA_HYDROSOLS.F L621 `ITRONC=1`, μ∈[0.85,0.92], seuil 0.1)하고 canonical red_clay에 OSOAA 규칙을 적용하면 절단계수 A=0.387로 발동 조건을 충족하지만, **HYD.Model 3(ExtData+UserProfile) 경로는 이 서브루틴을 실행하지 않는다**. 실증: `ITRONC=0` 강제 재빌드 A/B에서 출력 **비트 동일**.
- OSOAA 내부 표현 수렴 실증: Mie.NbGauss 100→300(L 200→600) A/B 최대 차 4.2e-9.
- 따라서 관측된 I(+0.64%)·Q 잔차는 절단 비대칭에서 오지 않는다.
- 주의: OSOAA를 HYD.Model 1/2(자체 granulometry Mie)로 쓰면 강제절단이 발동한다(A=0.387≫0.1). 향후 비교는 반드시 ExtData(Model 3) 경로 유지.

## 2. Q 오차 케이스의 특징 (figQ1, figQ2)

1. **근천저 집중**: mean|dev| 3.06%/max|I| @VZA5 → 0.19% @VZA≥20 (약 16배 감쇠). 상위 10개 오차 케이스 전부 VZA 5–10°.
2. **cos2φ 모드 구조**: dev 부호 = −sign(Q_ref). RAA 0/180°(Q<0)에서 최대 양의 dev, RAA 60–105°(Q>0)에서 최대 음의 dev.
3. **진폭 감쇠**: VZA≤10에서 OCRT Q = OSOAA Q × **0.57** (1:1 적합 기울기). 즉 OCRT의 근천저 Q 진폭이 참조보다 작다.
4. **수체 조성 무관**: pure↔red_clay 기하별 ΔQ_abs 상관 0.9995, 비율 5.31 = 두 케이스 수출광 세기비(max|I| 비 5.3). 오차는 상향 복사 세기에 비례하는 **계면 Q 전달 공통항**이다.
5. **기각된 원인**: 수중 커널(direct≡moment, 156점 전 점 동일), OSOAA 전개차수(L600 동일), 절단(§1), 위상 자료(§1·pure 무입자 동일 구조).
6. 상위 케이스의 수중 단일산란각은 147–155°로 특이 기하가 아니다 — 결정 변수는 순수하게 VZA(근천저)다.

## 3. 해석과 기존 기록의 정합

08-18 세션 기록(TODO 11+16): beamq(직달빔 Q 항) 병합 실험에서 "U 5배 개선, Q는 OSOAA 대비 소폭 악화 → **OSOAA 동일 항 결여 개연 → OSOAA 대비 Q 판정 기준 부적합**, 독립 폐형식(G-b2, −s1 규약) 검증으로 정본 병합(P4)". 현재 관측 — U 완전 정합(≤0.09%/max|I|) + Q 근천저 진폭 차 — 는 그 결정의 예상 서명과 일치한다. 즉 이 Q 오차는 OCRT 결함의 증거가 아니라 **참조코드 결여 항 개연 영역**이며, OSOAA는 이 성분의 심판으로 부적합하다.

## 4. 남은 조치 제안

- Q 근천저 진폭(0.57×)의 최종 심판은 제3 기준 필요: 편광 단일산란 해석해의 다중산란 확장 또는 벡터 MC 대조 1점(VZA 5, RAA 90/180) — P0 작업과 병행 등재 제안.
- 게이트 설계: Q는 OSOAA-상대 지표 대신 폐형식/제3 기준 상대 지표로 분리할 것(기존 결정의 명문화).

## 5. (추가 검증 2026-08-23) OSOAA 수출광 직접출력(WL dump)의 decouple 구현 확인

- 소스(OSOAA_SOS_CORE.F): Etape 3(물→공기 투과) 직후 `I1_ATM(표면준위,K) = Σ w·[IQU]1_SEA(0−)·TWA·2/μ` **대입** 시점에 덤프(거친/평면 해면 두 경로). 표면 반사광(하늘광·글린트)은 Etape 10에서 `I1_ATM = I1_ATM + ...`로 **그 이후** 가산 → 덤프 미포함.
- 리더(wl_read.py): (푸리에 m, 방향)별 산란차수 합산 후 TRPHI 규약(cos mφ/sin mφ, m=0 가중 1, φ=raa+180)으로 재구성. wl.txt 실측 구조(모드 29개, 쌍당 3–31 차수 레코드)와 정합. Rrs = WL/Ed(0+, Flux L26 Total_Down).

- OCRT 대칭 확인: fullgrid에서 Rrs_I ≡ Lu0plus_I/Ed0plus_air (최대 2.6e-13); rt_solver.c water-leaving 0+ 필드 아키텍처. 양쪽 정의 동일.

## 7. (A/B 실증) "둘 다 truncation을 동일 수치로 켜면?" — 아무것도 변하지 않는다

- OCRT 실행 실증: `OCRT_ADVANCED=1 --ocrt-mie-truncation` + OSOAA 창(OCRT_CAP_T1/T2=31.79/23.07)으로 red_clay 케이스 재실행 → `OCRT_TRUNC_SUMMARY A_tsm=0, b_eff=b_raw`, fullgrid 출력이 raw 런과 **최대차 0.000e+00 동일**.
- 원인(코드·수치 동시 확정): OCRT `rt_value_phase_interp_loglinear_truncate`는 OSOAA hydrosol 규칙의 정확한 미러다 — μ1/μ2=0.85/0.92(=θ 31.79°/23.07°), 임계 0.1, θ-로그선형 연속, A=2(1−χ₀), P12/P33 비율보존, **"연속이 전방 질량을 더하면(A≤0) 절단하지 않는다"(OSOAA 임계 규약 준수) + A<0.1 취소**.
- 정확 규칙으로 계산한 절단계수(555 nm):

| 위상 | OSOAA창 31.79/23.07 | 약캡 6/3 |
|---|---|---|
| canonical FR631 red_clay | A=−0.429 → **취소** (연속이 P11(0.5°)를 40→117로 과대) | A=−0.0009 → 취소 |
| 구판(08-19 stock) red_clay | A=−0.069 → **취소** | A=−0.0001 → 취소 |

- 물리적 이유: red_clay 위상의 전방 피크는 ~5° 이하에서 **평탄(plateau)**이다(canonical: 0.5° 40.1 / 1° 39.9 / 5° 36.5). 23–32° 구간 기울기의 로그선형 연속은 지수형 성장을 가정하므로 plateau를 과대추정 → 제거할 질량이 없다 → 규약상 자동 취소. 구판도 동일하게 취소된다.
- §1의 정정: §1에서 "OSOAA 규칙 적용 시 A=0.387 발동"이라 했던 것은 μ-공간 최소제곱 적합의 인공물이었다. 코드의 실제 규칙(θ-공간 2점 연속)으로는 **양쪽 모두, 양 세대 위상 모두 취소**다. ExtData 경로 우회 여부와 무관하게 결과 동일.
- 결론: red_clay TSM에 대해 truncation ON ≡ OFF (양 코드 공통). Q 근천저 진폭 차(0.57×)에 대한 절단 가설은 삼중 배제된다 — ① OFF 상태 동일(§1), ② ON 상태 취소로 동일(§7), ③ 무입자 pure water가 동일 Q 구조(§2-4). Q 문제는 위상·절단이 아니라 계면 Q 전달 항의 문제로 확정 유지.
- 참고: 과거 "둘 다 truncation ON으로 정합 통과" 이력은 (i) I 전용 비교였을 가능성(사용자 지적)과 (ii) red_clay에서는 당시에도 규칙상 취소 상태였을 가능성이 겹친다. ON/OFF가 결과를 가른 시절이 있었다면 그 대상은 A>0.1이 실제로 나오는 다른 위상(지수형 전방 성장 입자)이었을 것이다.

## 8. (판별 실험 2026-08-24) 근천저 Q 진폭 차의 소재 확정 — 물→공기 계면 투과

박막 대기 A/B와 수중장 직접 대조로 3단 분리를 완결했다 (figQ3_interface_transfer.png).

1. **박막 대기 A/B**: 양측 τ_R 0.0935485 → 0.0100 (OCRT --pressure 108.3128 hPa ↔ OSOAA AP.MOT 0.01, 나머지 동일). 근천저 Q 진폭비 **0.573 → 0.574 완전 불변**. |Q_ref|@VZA5도 3.51e-4→3.58e-4로 거의 불변 → 수출광 Q는 애초에 하늘광 편광 기원이 아니고, 하늘광-계면 결합 가설 기각. (부수 관찰: Rrs_I 중앙 편차는 +0.640→+0.813%로 오히려 증가 — I 잔차도 계면 사슬 성분임을 시사.)
2. **수중장(0−) 직접 대조** (Adv_UP L27 vs OCRT rrs, RAA90): I 중앙 −0.258%(기지 κ), **Q 근천저 기울기 0.999, 전 VZA |dev|≤0.07%/max|I|, U ≤0.04%** (U 53%는 φ-브랜치 매핑 오류였고 φ=270 브랜치로 정정 시 일치). **수면 아래에서는 양 코드의 벡터장이 사실상 완전 일치한다.**
3. **계면 전달비 프로파일** (T_Q/T_I ≡ (Q₀₊/Q₀₋)/(I₀₊/I₀₋), RAA90): 물리 기대는 θ→0에서 1(정면 프레넬 투과는 편광 보존). **OSOAA: VZA5에서 1.011로 기대와 일치.** **OCRT: VZA5에서 0.318** → 10° 0.741 → 20° 0.952 → 25° 이상에서 OSOAA에 수렴. T_I는 양측 모두 ~0.54로 평탄·일치.

**판정**: 근천저 수출광 Q 진폭 차(0.57×)는 **OCRT의 물→공기 거친면 투과 연산자가 근천저에서 Q(m=2 성분)를 비물리적으로 감쇠**시키는 데서 온다. 수면 아래 완전 일치 + OSOAA만 물리 기대 충족 + 대기 무관 — 세 증거가 모두 OCRT 계면 투과 쪽을 가리킨다.

**§3 해석의 정정**: "OSOAA 결여항 개연(beamq/P4)" 프레임은 이 성분에는 적용되지 않는다 — P4는 반사측 직달빔 Q 항이고, 여기서 확정된 것은 **투과측** 결함이다. G-b2 폐형식 검증이 이 투과 경로의 근천저를 커버했는지 재확인이 필요하다.

- rt_water_rt.c P2b `water_to_atm rough branch` — 디버그 로그상 m_max=2 처리 경로의 근천저(μ→1) 거동
- `[native-coupled-lut] exact_near_nadir=1` 특수처리 셀이 Q/U를 스칼라 근사하는지
- rt_air_water_coupling.c 의 상향 투과 뮬러 행렬 근천저 극한
- 결정타: 단일산란 폐형식(무대기·평면해면 극한)으로 T_Q/T_I(θ→0)=1 검증 케이스를 G게이트에 추가

## 9. (수정 완료 2026-08-25) 결함 특정·수정·검증 — U-열 부호접기 누락

- **결함**: `surface_T_wa_coxmunk_fourier_kernel`(거친면 물→공기 투과 푸리에 연산자)의 **m>0 U-열 부호접기 누락**. 동일 접기가 T_aw 커널에는 존재("OSOAA Step-7 storage/contraction 일치" 주석). 각도별 뮬러(`surface_T_coxmunk_trig`)는 독립 기준해와 전 성분 4자리 일치 — 결함은 푸리에 합성 단계에만 있었다.
- **특정 경로**: 단위 하니스(합성 m=2 장 → `rt_air_water_couple_water_to_atm`)가 RT 관측 서명(T_Q2 0.37@5°→0.94@20°, T_I=T_U2=1)을 정확 재현 → 콘볼루션 대수로 접기 누락 확정 → 접기 추가 시 (1,1,1).
- **수정**: 헬퍼 `ocrt_twa_fold_ucol_m()`을 직접 경로·FKC 경로 공통 적용. 소스 SHA `6a7da737…`, 바이너리 `70833d4d…`.
