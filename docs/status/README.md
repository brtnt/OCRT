# Development status documents

This directory holds the documents that track the state of the development itself, as opposed
to the user manual (`docs/manual/`), the technical records (`docs/technical/`) and the validation
records (`docs/validation/`). Both files were kept at the repository root until 2026-09-14.

| File | Contents | When to read |
|---|---|---|
| [OCRT_MIGRATION_STATUS_2026-08-23.md](OCRT_MIGRATION_STATUS_2026-08-23.md) | Cumulative development status, §1–§14 in date order: folder reorganisation, code lineage, data state, validation summaries, the platform-neutral canonical update, Mie data unification, TSM a*/b* revision, constituent slope options, and the PSSA → IPSS replacement (§14–§14.1) | When the history of a change or the state of the science gates is needed |
| [MIGRATION_README_2026-09-05_KO.md](MIGRATION_README_2026-09-05_KO.md) | Work hand-over note: how a new work session starts, the current state (v1.11.1), the inventory of what is in git and what stays on the local disk, the build and gate procedure, the update procedure for this repository, fixed rules, and the open items (§7) | When continuing development, or when checking what is still open |

Both documents record the state at the time they were written; the current usage of the code is
described in the manual. Paths inside the documents are relative to the repository root. Newer
sections are appended, earlier sections are not rewritten.
