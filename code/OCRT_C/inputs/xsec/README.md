# Gas cross-section LUTs

The six files contain 1 nm layer-resolved cross sections for H2O, O3, NO2, O2, CO2 and
CH4. Each header records gas, units, wavelength range, atmospheric layer order and HAPI
version. The first numeric row is the wavelength axis; subsequent rows correspond to
layers. Raw HITRAN/HAPI databases and a complete regeneration environment are not
included in this package.
