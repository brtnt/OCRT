# OCRT runtime inputs

Run OCRT from the `ocrt/` directory or through `../bin/ocrt` so these relative paths
resolve correctly. The official data catalog and provenance documents are at package
root `docs/`.

- `afgl_atm/`: atmospheric profiles
- `xsec/`: gas cross-section LUTs
- `water_iop/`: pure water, OCRT organic and CCRR Chl data
- `tsm_ahn/`: Ahn four-species mineral data
- top-level `.mie`: aerosol and retained legacy phase tables
- `deprecated/`: excluded diagnostic data
