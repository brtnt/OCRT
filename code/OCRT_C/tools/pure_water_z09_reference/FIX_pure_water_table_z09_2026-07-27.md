# 순수수 광특성표 전면 교체 + OSOAA 산란 Z09 통일 — 2026-07-27

지시 사항 세 가지를 처리했다. (1) 첨부 레퍼런스를 절대 표준으로 전면 교체,
(2) 분광 범위를 200 nm 부터 전부 포함, (3) OSOAA 산란을 Zhang 2009 로 교체.
추가로 온도·염분 상태값 적합성을 확인했다.

- 레퍼런스: `zo0_iop.txt` (200~2450 nm, 0.1 nm 간격, 열 = 파장·흡수·산란)
- 변환: 0.1 nm → 1 nm **적분(띠 평균)**. 각 정수 파장 L 에 대해 구간
  [L−0.5, L+0.5] 를 사다리꼴 적분하고 폭으로 나눈 값을 쓴다.
- 적용 범위: 200~2449 nm (2250 행), OCRT·OSOAA 양쪽 동일 자료.

---

## 1. 온도·염분 상태값 적합성 — 적합하다 (확인 완료)

지시하신 확인 항목이다. 코드를 읽어 판정했다.

**OCRT 흡수 온도 보정 규약**(`rt_water_iop.c`, `rt_water_iop_aw_T`):

```
return aw20 + psi * (T_celsius - T_ref);     // T_ref = 20.0
```

변수명이 `aw20` 이고 기준 온도가 20도다. **즉 표의 흡수는 20도 기준이어야 한다.**

**레퍼런스 파일 상태값**: 산란은 머리말에 "T=20도, 염분 38.4 g/kg" 으로 명시돼 있다.

**OCRT 설계 규약**(`rt_water_iop.h` 머리말): 산란은 Zhang 2009 (T=20도, S=38.4 g/kg),
굴절률은 Quan & Fry 1995 (T=20도, S=38.4 g/kg). **레퍼런스와 정확히 같다.**

**염분 흡수 보정**: 미구현이다(`rt_water_rt.c:3044`,
`(void)S_water_gkg; /* salinity not used in B.3 (psi_S deferred) */`). 따라서
염분 관련 충돌이 없다.

**결론: 첨부 파일의 상태값(T=20도, S=38.4 g/kg)은 OCRT 규약과 정확히 일치하므로
레퍼런스로 적합하다.** 온도 보정표(`psi_T_rottgers2014_OCRT.txt`)도 T_ref=20도이며,
검증 실행이 20도라 보정항이 0 이 되어 개입하지 않는다.

**결정적 확인**: `rt_water_iop.h` 머리말이 흡수 자료 출처를 이렇게 적고 있다 —
"Pope & Fry 1997 + Kou et al. 1993, **NASA OceanColor 배포 `water_coef_fine_z09.txt`
(200-2450 nm, 0.1 nm 간격)**". **첨부 파일이 바로 그 파일이다.** 즉 설계는 처음부터
이 자료를 쓰도록 돼 있었는데, 실제 표는 OSOAA 6개 밴드 값으로 재구성돼 있었다.
지적하신 "왜 레퍼런스를 줬는데 자의적으로 판단했는지" 의 답이 이것이다.

**남은 소소한 미확정 하나(정직한 고지)**: 레퍼런스 머리말은 산란에 대해서만 온도를
명시하고, 흡수의 측정 온도는 적지 않았다. OCRT 는 이 표를 20도 기준(`aw20`)으로
다루며 이는 NASA 배포본의 통상 규약이다. 검증이 20도에서 이뤄지므로 실무 영향은
없다. 또 온도 보정표는 400~900 nm 만 덮으므로, 그 밖 파장에서 20도가 아닌 온도를
쓰면 보정이 끝값 유지로 처리된다.

옳다는 것이 독립적으로 확인된다.

## 3. 산란 열 규약 — b(총산란)이며 bb 변환은 하면 안 된다

산란 열을 bb 로 변환해야 하는지 확인했다. 결론은 **변환하면 안 된다** 이며 근거가
세 가지다.

1. **코드**(`rt_water_iop.c`, `rt_iop_pure_water_eval`):
   `out->b = b_w;  out->bb = 0.5 * b_w;`
   즉 표의 산란 열은 b(총산란)로 읽히고, **후방산란은 OCRT 가 내부에서 0.5 를
   곱해 만든다.** 반환 함수 `rt_water_iop_bw` 도 열을 그대로 돌려준다(계수 미적용).
2. **레퍼런스 머리말**: "for backscatter, we use 0.5*bw" — 같은 규약이다.
3. **실측**: 표에 0.5×b(=bb)를 넣으면 OSOAA 정합이 **54 %** 로 무너진다(반사도가
   절반). 0.5 가 두 번 곱해지기 때문이다.

따라서 레퍼런스의 b 를 표에 그대로 넣었다.

## 4. OSOAA 산란 Z09 교체 — 지시대로 수행

교체 전 상태를 확인하니, OSOAA 는 이미 2026-06-22 에 Morel 1974 공식 계산 대신
표를 읽도록 수정돼 있었다(`OSOAA_PROFILE.F`, `SIG_DIF_MOREL = SIG_DIF_TABULATED`).
그러나 **표 자체**(`fic/OSOAA_SEA_MOL_COEFFS_JUNE_2013.txt`)의 산란 열은 여전히 옛
값이라 Z09 와 3.5~12.5 % 달랐다(파장 의존). 흡수 열은 이미 레퍼런스와 일치했다.

조치: OSOAA 표를 OCRT 와 **동일한 띠평균 자료**로 교체했다(200~2449 nm, 2250 행,
행수 상한 CTE_NBWA_MAX=2500 이내). 이제 두 코드가 완전히 같은 순수수 자료를 쓴다.
원본은 `/tmp/OSOAA_TABLE_OLD.txt` 에 보관했다.
