# Gas cross-section tables

The six files hold 1 nm layer-resolved absorption cross sections of H2O, O3, NO2, O2, CO2 and
CH4. Each header records the gas, units, wavelength range, atmospheric layer order and HAPI
version. The first numeric row is the wavelength axis; the following rows are the layers. The raw
HITRAN/HAPI databases and a complete regeneration environment are not included in this package.

---

# 기체 흡수 단면적 표

여섯 파일은 H2O, O3, NO2, O2, CO2, CH4 의 1 nm 층별 흡수 단면적을 담는다. 각 머리글에 기체, 단위, 파장
범위, 대기 층 순서, HAPI 버전이 기록되어 있다. 첫 수치 행은 파장 축이고 이후 행은 층에 대응한다. 원본
HITRAN/HAPI 데이터베이스와 완전한 재생성 환경은 이 패키지에 포함되지 않는다.
