# AFGL / RFM atmosphere profiles

A runtime profile is selected with `--atm-profile`. Each file header documents the columns, the
source lineage and the conversion details. `_pre_RFM_backup/` is kept only for audit.
`afgl_userdef.dat` is the fixed-path template for a user-defined profile.

---

# AFGL / RFM 대기 프로파일

실행 시 프로파일은 `--atm-profile` 로 선택한다. 각 파일 머리글에 열, 출처 계보, 변환 방법이 적혀 있다.
`_pre_RFM_backup/` 은 감사용으로만 보관한다. `afgl_userdef.dat` 는 사용자 정의 프로파일의 고정 경로
템플릿이다.
