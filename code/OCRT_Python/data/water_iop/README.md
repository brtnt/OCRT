# pyOCRT water IOP data

The 2026-07-26 EAP update replaced the three obsolete phytoplankton `.mie` files with 17
regenerated representative files under `eap/`.

Compatibility aliases:

- `pico` → `EAP_15_Synechococcus_D1p2.mie`
- `nano` → `EAP_12_Hapto_Prymnesiaceae_D4.mie`
- `micro` → `EAP_02_Diatoms_centric_D6.mie`

All 17 canonical `eap_*` names are exposed by the Python CLI. The original source data and the
reproducible layered-sphere generator are included in the package.

# pyOCRT 해수 IOP 자료

2026-07-26 EAP 갱신에서 옛 식물플랑크톤 `.mie` 파일 세 개를 `eap/` 아래의 재생성 대표 파일 17개로
바꿨다.

호환 별칭:

- `pico` → `EAP_15_Synechococcus_D1p2.mie`
- `nano` → `EAP_12_Hapto_Prymnesiaceae_D4.mie`

패키지에 포함되어 있다.
